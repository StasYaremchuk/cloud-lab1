# Масштабування за розкладом (Бонусне Завдання 8)

Оскільки Google Cloud Run не має вбудованого параметра "розклад" у Terraform, я реалізував логіку дня і ночі через змінну Terraform is_night.

У файлі main.tf я використав тернарний оператор: min_instance_count = var.is_night ? 0 : 2.
Це дозволяє мені керувати кількістю екземплярів за допомогою однієї команди:
- Вдень: terraform apply -var="is_night=false". Система тримає 2 екземпляри для швидкої обробки навантаження.
- Вночі: terraform apply -var="is_night=true". Система масштабується до 0, коли немає трафіку, щоб зекономити кошти.

Вимірювання холодного старту: Коли екземпляр "спить" (кількість екземплярів 0), перший запит користувача займає близько 3-4 секунд, оскільки Google має запустити контейнер. Наступні запити відповідають миттєво.

Розрахунок місячної економії:
Вартість роботи одного екземпляра Cloud Run становить приблизно $15 на місяць. Вдень ми тримаємо 2 екземпляри. Вночі (приблизно 10 годин на добу) ми масштабуємось до 0 і не платимо за простій. Масштабування до нуля дозволяє заощадити близько 40% бюджету на нічний час.
