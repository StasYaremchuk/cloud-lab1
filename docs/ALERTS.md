# Сповіщення (Завдання 4)

Умова спрацьовування:
- Метрика: Request Latency (p95).
- Поріг: > 0.5 секунди (500 мс).
- Тривалість: 2 хвилини.

Під час запуску навантаження мені на пошту прийшло два листи:
1. Alert firing - коли латентність перевищила 500 мс 
2. Alert resolved - коли навантаження впало і латентність повернулася в норму.
