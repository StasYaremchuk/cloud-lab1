# Навантажувальне тестування (Завдання 2)

Для тестування я використав інструмент k6. Скрипт лежить у папці loadtest/script.js.
Запуск відбувається командою: k6 run loadtest/script.js

Сценарій імітує звичайних користувачів: одна операція запису (створення літака) і вісім операцій читання (отримання списку). 
Тест триває 9 хвилин і має три етапи:
1. Наростання (Ramp-up): навантаження плавно зростає від 0 до 50 користувачів за 2 хвилини.
2. Плато (Plateau): 5 хвилин тримається стале навантаження на рівні 50 користувачів.
3. Спад (Ramp-down): 2 хвилини навантаження плавно спадає до нуля.

Результати першого тестування (50 користувачів, без кешу):
- Всього запитів: 28 908
- Помилок: 0%
- Швидкість: 53.47 запитів на секунду
- Час відповіді (p50): 551 мс
- Час відповіді (p95): 1.59 секунди
- Час відповіді (p99): 11.23 секунди

Загалом сервіс впорався з навантаженням. Помилок не було. Ці результати використовуються для порівняння в Завданні 5.
