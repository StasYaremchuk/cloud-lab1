# Навантажувальне тестування (Завдання 2)

Для тестування я використав інструмент k6. Скрипт лежить у папці `loadtest/script.js`.

Сценарій імітує звичайних користувачів: одна операція запису (створення літака) і вісім операцій читання. Тест триває 9 хвилин (наростання, плато, спад).

Результати тестування (50 користувачів, з кешем та обмеженням concurrency=5):
- Всього запитів: 22 968
- Помилок: 0% (всі 100% успішні)
- Швидкість: 42.35 запитів на секунду
- Час відповіді (p50): 324.82 мс
- Час відповіді (p95): 2.74 секунди

Сервіс успішно витримав навантаження. Завдяки обмеженню одночасних запитів на екземпляр (concurrency=5), Cloud Run зміг розподілити навантаження між кількома екземплярами.
